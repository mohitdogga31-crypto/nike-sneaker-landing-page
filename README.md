# Nike Sneaker Landing Page

![Nike Sneaker Landing Page]<img width="1856" height="1434" alt="Nike Page 3" src="https://github.com/user-attachments/assets/fd0f450c-934a-4fe8-8483-f06579e8360a" />


A modern Nike-inspired sneaker landing page designed with a premium dark aesthetic, strong visual hierarchy, and product-focused UI.

## 🎨 Design

This landing page was designed in Figma with a focus on creating a premium sneaker e-commerce experience.

### Key Design Elements

- Minimal dark interface
- Strong typography
- Product-focused hero section
- Premium sneaker presentation
- Featured product cards
- Clean navigation
- Modern shadows and lighting
- Clear visual hierarchy

## ✨ Features

- Hero product showcase
- Navigation bar
- Featured sneaker section
- Product cards
- Product pricing
- Search interface
- Shopping cart interface
- Add-to-cart interaction
- Premium dark theme
- Responsive layout

## 🛠️ Tools & Technologies

- Figma
- HTML5
- CSS3
- JavaScript
- Git
- GitHub

## 🎯 Design Goals

The main goal of this project was to create a visually engaging sneaker e-commerce landing page while focusing on:

- Visual hierarchy
- Consistency
- Readability
- Product focus
- Minimalism
- User-friendly navigation
